# Passive RF測位の基礎（1～3）

本資料は、添付されたPassive RF測位サンプルコードの背景理論として、

1.  Passive RF測位とは
2.  TDOA (Time Difference of Arrival) の原理
3.  FDOA (Frequency Difference of Arrival) の原理

を数式を中心に解説する。

------------------------------------------------------------------------

# 1. Passive RF測位とは

Passive RF（Passive Radio
Frequency）は、自ら電波を送信せず、対象物から自然に放射される電波や通信電波を複数の受信局で受信し、その情報から対象物の位置・速度を推定する技術である。

受信局を

-   Station 1
-   Station 2
-   Station 3

とし、未知の物体位置を

\[ `\mathbf{x}`{=tex}=
```{=tex}
\begin{bmatrix}
x\\
y
\end{bmatrix}
```
\]

速度を

\[ `\mathbf{v}`{=tex}=
```{=tex}
\begin{bmatrix}
v_x\\
v_y
\end{bmatrix}
```
\]

とする。

各局位置を

\[ `\mathbf{s}`{=tex}\_i \]

とすると距離は

\[ r_i=\|`\mathbf{x}`{=tex}-`\mathbf{s}`{=tex}\_i\| \]

である。

Passive RFでは

-   到達時間差（TDOA）
-   ドップラー周波数差（FDOA）

のみを観測する。

絶対送信時刻や絶対送信周波数は不要である。

------------------------------------------------------------------------

# 2. TDOAの原理

## 2.1 到達時間

局 i に到達する時間は

\[ t_i=t_0+`\frac{r_i}{c}`{=tex} \]

ここで

-   (t_0)：送信時刻
-   (c)：光速

である。

送信時刻は未知なので直接位置は求められない。

------------------------------------------------------------------------

## 2.2 時間差

局1を基準にすると

\[ `\Delta `{=tex}t\_{21}=t_2-t_1 \]

となり

\[ `\Delta `{=tex}t\_{21} = `\frac{r_2-r_1}{c}`{=tex} \]

同様に

\[ `\Delta `{=tex}t\_{31} = `\frac{r_3-r_1}{c}`{=tex} \]

となる。

コード中では

``` julia
tdoa21 = (ranges[2]-ranges[1])/C
tdoa31 = (ranges[3]-ranges[1])/C
```

として計算している。

------------------------------------------------------------------------

## 2.3 距離差

時間差に光速を掛けると

\[ `\Delta `{=tex}r\_{21}=c`\Delta `{=tex}t\_{21} =r_2-r_1 \]

となる。

これは

「局2までの距離−局1までの距離」

を意味する。

------------------------------------------------------------------------

## 2.4 双曲線

距離差一定は

\[ \|`\mathbf{x}`{=tex}-`\mathbf{s}`{=tex}\_2\| -
\|`\mathbf{x}`{=tex}-`\mathbf{s}`{=tex}*1\| = `\Delta `{=tex}r*{21} \]

で表される。

これは双曲線の定義そのものである。

したがって

1本のTDOA

↓

1本の双曲線

になる。

さらに

\[ `\Delta `{=tex}r\_{31} =
\|`\mathbf{x}`{=tex}-`\mathbf{s}`{=tex}\_3\| -
\|`\mathbf{x}`{=tex}-`\mathbf{s}`{=tex}\_1\| \]

を加えると

2本の双曲線の交点が位置候補になる。

------------------------------------------------------------------------

# 3. FDOAの原理

## 3.1 ドップラー効果

送信周波数を

\[ f_0 \]

とすると受信周波数は

\[ f_i = f_0 `\left`{=tex}( 1-`\frac{\dot r_i}{c}`{=tex} `\right`{=tex})
\]

である。

ここで

\[ `\dot `{=tex}r_i \]

は距離速度（Range Rate）である。

------------------------------------------------------------------------

## 3.2 距離速度

視線方向単位ベクトルを

\[ `\mathbf{u}`{=tex}\_i = `\frac{\mathbf{x}-\mathbf{s}_i}`{=tex}
{\|`\mathbf{x}`{=tex}-`\mathbf{s}`{=tex}\_i\|} \]

とすると

\[ `\dot `{=tex}r_i = `\mathbf{u}`{=tex}\_i\^T `\mathbf{v}`{=tex} \]

となる。

つまり

距離速度とは

「速度ベクトルの視線方向成分」

である。

------------------------------------------------------------------------

## 3.3 FDOA

局1との差を取ると

\[ `\Delta `{=tex}f\_{21} = f_2-f_1 \]

となる。

展開すると

\[ `\Delta `{=tex}f\_{21} = -`\frac{f_0}{c}`{=tex}
(`\dot `{=tex}r_2-`\dot `{=tex}r_1) \]

さらに

\[ `\dot `{=tex}r_i=`\mathbf{u}`{=tex}\_i\^T`\mathbf{v}`{=tex} \]

より

\[ `\boxed{
\Delta f_{21}
=
-\frac{f_0}{c}
(\mathbf{u}_2-\mathbf{u}_1)^T
\mathbf{v}
}`{=tex} \]

同様に

\[ `\boxed{
\Delta f_{31}
=
-\frac{f_0}{c}
(\mathbf{u}_3-\mathbf{u}_1)^T
\mathbf{v}
}`{=tex} \]

となる。

------------------------------------------------------------------------

## 3.4 線形方程式

まとめると

\[ A`\mathbf{v}`{=tex}=b \]

となる。

\[ A=
```{=tex}
\begin{bmatrix}
(\mathbf{u}_2-\mathbf{u}_1)^T\\
(\mathbf{u}_3-\mathbf{u}_1)^T
\end{bmatrix}
```
\]

\[ b= -`\frac{c}{f_0}`{=tex}
```{=tex}
\begin{bmatrix}
\Delta f_{21}\\
\Delta f_{31}
\end{bmatrix}
```
\]

である。

コード中では

``` julia
velocity = A \ b
```

とそのまま解いている。

------------------------------------------------------------------------

# まとめ

Passive RF測位では、

-   **TDOA** が位置を拘束する（双曲線）
-   **FDOA** が速度を拘束する（速度平面上の直線）

という役割を持つ。

本コードでは両者を同時に利用することで、未知の位置と速度を一括推定している。
